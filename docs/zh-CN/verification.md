# 验证说明

[项目首页](../../README.zh-CN.md) · [开发说明](development.md) · [English](../verification.md)

验证分别记录源码检查、安装包检查、原生桌面与视觉检查。每项结果关联对应提交或安装包；CLI 读取成功不能证明窗口可用。

## 源码检查

对改动后的源码运行[开发说明](development.md)中的检查。Git 测试使用独立临时仓库，对比查看前后的文件、暂存区、引用、配置和 LFS 对象。不要在个人仓库中构造测试变化。

## 安装包检查

[Desktop CI](https://github.com/oil-oil/oil-git/actions/workflows/build.yml) 检查 macOS ARM64、macOS Intel 与 Windows x64 的实际安装。结果以该次运行记录为准，配置了任务、跳过的任务或本地交叉编译不算通过。

`scripts/ci-install-smoke.mjs` 安装或复制产物后运行其中的真实程序和启动器。检查帮助、版本、Skill、中文与空格路径、暂存范围、LFS、错误退出码及仓库字节不变。JSON 报告记录平台、架构、安装包 SHA-256、完成项目与限制，和安装包一起上传以便查看。

## 原生桌面走查

在目标平台打开已安装应用和独立真实仓库，按改动范围检查：

- 选择器与启动器打开、重复请求复用窗口、最近项目移除与启动恢复。
- 文件通知、前台刷新保留阅读内容；同步流光位于工具栏下方，空闲时停止。
- 提交历史、筛选、分页、详情，以及暂存、未暂存与冲突文件；与本地 Git 输出核对。
- 长行换行、自然行高、真实行号、分栏调整、键盘选中与滚动保持。
- 真实夹具中的图片新增、删除、修改、100% 垂直布局、音视频、字节回退、截断与行归属。
- 切换中英文与三个主题不丢失状态；检查对话框、提示、无障碍名称、复制反馈与较长翻译。
- 减少动态效果和隐藏视图；复制按钮在预留位置渐入，不推动标题。

保存代表性截图，记录系统、架构、应用提交和安装包摘要，明确未检查的范围。本机日志和截图保存在公开文档之外，PR 可关联相关证据。

## 平台边界

macOS 使用通用包，同一个 DMG 需要在 Apple Silicon 和 Intel 分别安装验证。Windows 使用 x64 NSIS。CI 安装检查覆盖 CLI 和资源，不覆盖 WebView 渲染、文件通知、窗口交互与视觉质量；这些需要在目标机器走查。

发布的测试包可能早于默认分支的功能。复现时查看发布提交和说明，不能把当前源码的检查结果套用到旧安装包。
